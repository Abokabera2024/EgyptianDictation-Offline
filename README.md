النص النهائي فقط. تعطل العامل لا يُسقط Word، وإيقاف الجلسة يمنع إدراج النتائج
المتأخرة.

## البناء

المصدر محفوظ دون ملفات البناء المؤقتة. بعد استنساخ المستودع، استخدم
`git submodule update --init --recursive` للحصول على نسخة `transcribe.cpp`
المثبتة، ثم ضع النموذج والملفات الرسمية المطلوبة محليًا كما يلي. يتوفر مثبّت
v2.5 الكامل وملف مكتبات التشغيل الأصلية ضمن صفحة Releases الخاصة بالمستودع؛
فكّ ملف المكتبات داخل `NativeSTT/runtime` عند بناء نسخة جديدة. النموذج ليس
جزءًا من تاريخ Git.

ضع النموذج باسم `cohere-transcribe-arabic-07-2026-Q5_K_M.gguf` في جذر المشروع،
والمثبتين الرسميين المحددين في `prerequisites/manifest.json` داخل مجلد `prerequisites`،
ثم نفّذ:

```powershell
.\scripts\build-release.ps1 -IncludeModel
```

ينتج البناء حزمة تطبيق صغيرة لتحديث البرنامج دون إعادة توزيع النموذج، وحزمة
كاملة للاستخدام دون إنترنت. أداة القياس المدمجة:

```powershell
ArabicSTTWorker.exe --benchmark <wav-folder> --model <model.gguf> --output results.csv
```

تتضمن النتائج مدة الصوت وزمن الاستدلال وRTF والنص. لا تحفظ النسخة العادية
التسجيلات أو النصوص في السجل، ويحتوي `config/domain_lexicon.json` على مصطلحات
مرجعية فقط ولا ينفذ استبدالات لغوية تلقائية.
