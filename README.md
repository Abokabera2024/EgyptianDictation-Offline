# الإملاء العربي والمصري دون إنترنت

برنامج إملاء صوتي يعمل محليًا داخل مايكروسوفت وورد المكتبي. يحوّل الكلام العربي، بما فيه اللهجة المصرية، إلى نص يُدرج في موضع مؤشر الكتابة الحالي؛ ويمكنك النقر في موضع آخر ومتابعة الإملاء هناك.

> **الإصدار الحالي: ٢٫٥** · **النظام: ويندوز ١٠ أو ١١ بنظام ٦٤ بت** · **التشغيل: دون اتصال بالإنترنت بعد التثبيت**

[تنزيل الإصدار](https://github.com/Abokabera2024/EgyptianDictation-Offline/releases/tag/v2.5.0) · [دليل الاستخدام](docs/USER_GUIDE_AR.md) · [تقرير التحقق من الإصدار](docs/RELEASE_REPORT_2.5.0.md) · [شروط الاستخدام](docs/TERMS_AR.txt)

## المزايا الرئيسية

- **كتابة حيث يوجد المؤشر:** تُدرج كل عبارة نهائية في الموضع المحدد حاليًا داخل وورد، لا في موضع بدء الجلسة فقط.
- **إملاء عربي ومصري:** يدعم أمر «أول السطر» لبدء فقرة جديدة، ويضبط اتجاه السنوات والتواريخ المكتشفة حتى تُقرأ من اليسار إلى اليمين.
- **استجابة مستمرة:** تُقسَّم العبارات وتُعالج محليًا، ويظل النموذج محمّلًا أثناء الجلسة لتقليل التوقف بين العبارات.
- **اختيار مناسب للعتاد:** يعمل على المعالج المركزي، ويمكنه استخدام تسريع الرسوميات المتوافق تلقائيًا مع الرجوع إلى المعالج المركزي عند الحاجة.
- **حزمة كاملة مستقلة:** تضم النموذج والمحرك والمكتبات المطلوبة ومثبّت متطلبات مايكروسوفت، دون تنزيل إضافي أثناء التثبيت.
- **موافقة صريحة:** يعرض المثبّت شروط الاستخدام، ولا يبدأ التثبيت إلا بعد تحديد خانة الموافقة غير المحددة مسبقًا.

> **مهم:** التعرف على الكلام قد يخطئ في الأسماء والأرقام والتواريخ وعلامات الترقيم، وقد يلتقط صوتًا قريبًا. راجع النص وصححه قبل حفظه أو تقديمه أو الاعتماد عليه.

## المتطلبات

| العنصر | المطلوب |
| :--- | :--- |
| نظام التشغيل | ويندوز ١٠ أو ١١، بنظام ومعالج ٦٤ بت |
| محرر المستندات | نسخة مايكروسوفت وورد المكتبية |
| الصوت | ميكروفون يعمل ومسموح له بالوصول إلى النظام |
| الصلاحيات | صلاحية تثبيت البرامج؛ قد يظهر طلب موافقة المسؤول |

الأجهزة بنظام ٣٢ بت، ومعالجات آرم، والأنظمة الأخرى غير مدعومة في هذا الإصدار.

## التثبيت لأول مرة

1. نزّل **الحزمة الكاملة** من [صفحة الإصدار](https://github.com/Abokabera2024/EgyptianDictation-Offline/releases/tag/v2.5.0):

```text
EgyptianDictation-Setup-Full-v2.5.zip
```

2. فك ضغط الملف بأدوات ويندوز، ثم احفظ مستنداتك وأغلق وورد. شغّل الملف الناتج:

```text
EgyptianDictation-Setup-Full-v2.5.exe
```

3. اقرأ شروط الاستخدام وحدد الموافقة إذا قبلتها، ثم تابع التثبيت. تحتوي الحزمة النموذج ومكتبات التشغيل، وتثبّت متطلبات مايكروسوفت المرفقة عند غيابها أو قِدمها. أعد تشغيل ويندوز إذا طلب المثبّت ذلك.

4. افتح وورد بعد اكتمال التثبيت. سيظهر تبويب **«الإملاء دون إنترنت»**.

الحزمة الأصغر مخصصة **لتحديث جهاز ثُبّت عليه النموذج الصحيح سابقًا**، وليست بديلًا عن الحزمة الكاملة عند التثبيت الأول:

```text
EgyptianDictation-Setup-App-v2.5.exe
```

وُضعت الحزمة الكاملة داخل ملف مضغوط لأن حجم ملف التثبيت الأصلي يتجاوز حد الملف الواحد في مرفقات الإصدار. فك الضغط خطوة تنزيل فقط؛ لا يحتاج تشغيل البرنامج بعدها إلى أداة ضغط أو مكتبات إضافية.

## الإملاء داخل وورد

1. انقر داخل المستند في موضع الكتابة المطلوب.

2. افتح تبويب **«الإملاء دون إنترنت»** واضغط **«بدء الإملاء»**.

3. انتظر اكتمال تجهيز المحرك في المرة الأولى، ثم تحدث بوضوح واترك وقفة قصيرة بين العبارات. لا تُدرج الفرضيات المؤقتة؛ يظهر النص بعد اعتماد العبارة.

4. للكتابة في سطر أو صفحة أخرى، **انقر** عند الموضع الجديد ثم واصل الكلام. تحريك الماوس دون نقر لا ينقل مؤشر الكتابة.

5. اضغط **«إيقاف»** عند الانتهاء؛ ينتظر البرنامج إكمال آخر كلام قبل إغلاق الجلسة.

## خصوصية المعالجة وبنية البرنامج

يعالج التطبيق الصوت محليًا ولا يعتمد على خدمة إملاء سحابية. تتواصل إضافة وورد مع تطبيق الالتقاط ومحرك التعرف عبر قنوات محلية داخل ويندوز. يحمل المحرك النموذج في عملية مستقلة، ثم يعيد النص النهائي لإدراجه في المستند.

```text
الميكروفون ← التقاط الصوت وتقسيم العبارات ← التعرف المحلي ← النص النهائي ← موضع المؤشر في وورد
```

لا يتحكم التطبيق في إعدادات وورد أو ويندوز أو البرامج الأخرى. تقع على المستخدم مسؤولية مراجعة النص، وحماية المستندات، والحصول على أي موافقات لازمة قبل إملاء كلام أشخاص آخرين.

## التحقق من سلامة التحميل

ملف التثبيت غير موقّع رقميًا حاليًا، وقد يظهر تحذير من ويندوز. تحقق من بصمة الحزمة الكاملة بعد تنزيلها:

```powershell
Get-FileHash .\EgyptianDictation-Setup-Full-v2.5.zip -Algorithm SHA256
```

البصمة المتوقعة للملف المضغوط:

```text
42420D8569BE35AA34327BE0408CA4928F8B6775882F81596D89F4F12574BFA2
```

البصمة المتوقعة لملف التثبيت بعد فك الضغط:

```text
120CB03280D4AC02FA6A9A2F024E772A75668EFE7F087D93B341B25B19CED2B7
```

## البناء من المصدر

يحفظ المستودع الكود والاختبارات والوثائق ومرجع نسخة المحرك الأصلية. لا تُحفظ أوزان النموذج وملفات البناء المؤقتة ومثبّتات مايكروسوفت الكبيرة في تاريخ المستودع.

1. استنسخ المستودع مع المشروع الفرعي، أو نفّذ الأمر الآتي بعد الاستنساخ:

```powershell
git submodule update --init --recursive
```

2. وفّر حزمة تطوير دوت نت ٨ محليًا في المسار التالي. هذه أداة **للبناء فقط**؛ لا يحتاجها مستخدم المثبّت الكامل:

```text
.dotnet\dotnet.exe
```

3. نزّل ملف مكتبات المحرك من صفحة الإصدار، وفكّه داخل المجلد الموضح:

```text
EgyptianDictation-NativeRuntime-v2.5.zip
NativeSTT\runtime\
```

4. ضع ملف النموذج في جذر المشروع، وتحقق من بصمته المبينة في [تقرير الإصدار](docs/RELEASE_REPORT_2.5.0.md):

```text
cohere-transcribe-arabic-07-2026-Q5_K_M.gguf
```

5. ضع مثبّتَي مايكروسوفت الرسميين في مجلد المتطلبات. تُثبت بصماتهما المتوقعة في [بيان المتطلبات](prerequisites/manifest.json):

```text
prerequisites\vc_redist.x64.exe
prerequisites\NDP48-x86-x64-AllOS-ENU.exe
```

6. ابنِ الحزمتين الكاملة والخاصة بالتحديث:

```powershell
.\scripts\build-release.ps1 -Version 2.5.0 -IncludeModel
```

لاختبار المشروع دون تشغيل اختبارات النموذج الثقيلة:

```powershell
.\.dotnet\dotnet.exe test tests\EgyptianDictation.Tests\EgyptianDictation.Tests.csproj -c Release --filter 'Category!=RealModel&Category!=RealModelGpu'
```

اجتاز إصدار ٢٫٥ **٥٦ اختبارًا من أصل ٥٦** في هذه المجموعة. لم يُتحقق بعد من التثبيت النهائي على جهاز نظيف؛ راجع [تقرير الإصدار](docs/RELEASE_REPORT_2.5.0.md) قبل التوزيع الواسع.
