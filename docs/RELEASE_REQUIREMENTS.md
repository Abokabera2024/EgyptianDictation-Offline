# متطلبات حزمة الإصدار

الحزمة النهائية يجب أن تحقق كل الشروط التالية:

1. ملف تثبيت واحد للمستخدم النهائي.
2. تستهدف Windows 10/11 x64 مع Word Desktop على x86 أو x64 بعد التثبيت، بشرط توافق إصدار Word مع النظام. لا تدعم Windows 7/8.1 أو أجهزة x86/ARM في هذه الحزمة. لا يُدّعى التوافق النهائي قبل الاختبار على جهاز نظيف.
3. لا تحتاج Python أو .NET SDK أو Visual Studio أو Git أو اتصالًا بالإنترنت. تتضمن حزمة ‎.NET 8‎ المستقلة والمثبتين الرسميين غير المتصلين لـ Visual C++ x64 و.NET Framework 4.8 عند الحاجة.
4. تتضمن نموذج ASR المختار وملفات tokenizer وكل المكتبات الأصلية اللازمة.
5. ينشر المضيف كحزمة .NET self-contained لـ `win-x64`.
6. يتضمن `ArabicSTTWorker.exe` الأصلي وملفات `transcribe.cpp` الخاصة بالـCPU، دون Python أو PyTorch أو CUDA.
7. يسجل إضافة Word من داخل المثبت ذي صلاحية المسؤول، ولا يتطلب VSTO.
8. يدعم التثبيت والإزالة دون ترك تسجيلات COM/VSTO أو عمليات بدء تشغيل يتيمة.
9. يُختبر على جهاز/آلة افتراضية نظيفة مع الشبكة محجوبة طوال التثبيت وأول تشغيل قبل النشر العام، ومع Word مثبت على الجهاز.
10. ينتج تقرير محتويات وتراخيص وبصمات SHA-256 لكل ملف نموذج واعتماد طرف ثالث.

لا يعد المشروع جاهزًا للإصدار بمجرد نجاحه على جهاز التطوير؛ اجتياز اختبار البيئة النظيفة شرط نهائي.
كما يجب التأكد من أهلية إعادة توزيع Visual C++ بموجب شروط ترخيص Visual Studio قبل النشر العام.
