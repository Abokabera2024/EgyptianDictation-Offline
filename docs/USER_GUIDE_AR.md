# دليل الاستخدام

1. شغّل حزمة التثبيت الكاملة v2.5 على Windows 10/11 x64 مع Word Desktop. تحتوي
   النموذج والمكتبات المطلوبة، وتثبّت Visual C++ x64 أو .NET Framework 4.8 من
   داخل الحزمة عند غيابهما أو قِدمهما، دون تنزيل شيء. إذا طلب المثبت إعادة
   التشغيل، أعد تشغيل Windows قبل استخدام Word. أما حزمة تحديث التطبيق فقط
   فتتطلب نموذجًا صحيحًا موجودًا مسبقًا في
   `C:\ProgramData\EgyptianDictation\Models\cohere-transcribe-arabic-07-2026-Q5_K_M.gguf`.
2. أغلق Word وافتحه من جديد بعد التثبيت.
3. ضع المؤشر في المكان المطلوب واضغط «بدء الإملاء».
4. انتظر رسالة تحميل النموذج في المرة الأولى، ثم تكلم واترك وقفة قصيرة في نهاية العبارة.
5. لا تُكتب الفرضيات المؤقتة؛ تُدرج العبارة النهائية فقط عند المؤشر.
6. اضغط «إيقاف» لإلغاء أي نتيجة لم تكتمل ومنع إدراج نص قديم.

كل المعالجة محلية. لا يُحفظ الصوت ولا يُرسل الصوت أو النص أو المستند إلى الإنترنت.
يمكن تغيير مسار النموذج وإعدادات VAD في
`C:\ProgramData\EgyptianDictation\engine-settings.json`.
