# تقرير إصدار الإملاء العربي دون إنترنت 0.2.0

التاريخ: 22 سبتمبر 2026

## النتيجة

أصبح مسار الإنتاج يعتمد حصريًا على نموذج `CohereLabs/cohere-transcribe-arabic-07-2026` بصيغة `Q5_K_M GGUF`، من خلال عامل Windows محلي دائم `ArabicSTTWorker.exe` ومحرك `transcribe.cpp`. لا يحتاج التشغيل النهائي إلى Python أو PyTorch أو CUDA أو اتصال بالإنترنت.

ظل تكامل Microsoft Word وتسجيل الميكروفون والإدراج عند موضع المؤشر كما هو. يحمل العامل النموذج مرة واحدة، ويتواصل التطبيق معه عبر Named Pipes محلية، ويدعم الإلغاء وإعادة التشغيل بعد التعطل.

أضيفت معالجة آمنة لإزالة أثر فك الترميز `@@@فراغ` فقط. لم تُضف استبدالات عمياء بين كلمات مثل «الخانات» و«الخيانة»، لأن ذلك قد يغيّر المعنى القانوني للنص الصحيح.
